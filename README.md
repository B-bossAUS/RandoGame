# Rando Dash

A small browser arcade game. Dodge the falling red spikes, collect gold coins, and survive as long as you can. Every 10 seconds a random **chaos modifier** changes the rules.

## Play

Open `index.html` in any modern browser. There's no build step and nothing to install.

## Controls

- **← / →** or **A / D** to move
- **Drag** on the game area (mouse or touch)
- **Space / Enter** to start or restart

## Chaos modifiers

| Modifier | Effect |
| --- | --- |
| Speed Frenzy | Everything falls twice as fast |
| Slow Motion | The world slows down |
| Reversed Controls | Left is right, right is left |
| Tiny Mode / Giant Mode | Your size changes |
| Coin Rain | Lots of coins, each worth double |
| Gravity Flip | Stuff falls upward and you move to the top |
| Blackout | You can only see near yourself |
| Slippery Floor | Movement has momentum |
| Calm | No modifier |

You get 1 point per second survived and 10 points per coin. You have 3 lives, and your best score is saved in the browser.
